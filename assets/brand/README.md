# Antoninus Hines Foundation — logo files

Vector "AH" traced from the supplied logo artwork; the wordmark on the site is live text in Poppins SemiBold.

| File | Use |
|---|---|
| `ah-monogram.svg` | Master vector, original stroke weight. Light backgrounds, large sizes, print. |
| `ah-monogram-light.svg` | Same, lighter greens for dark backgrounds. |
| `ah-monogram-bold.svg` | Slightly heavier strokes for small sizes (site header on cream). |
| `ah-monogram-bold-light.svg` | Heavier + lighter greens (site header over the dark hero, footer). |
| `logo-full.png` | Full stacked logo, transparent PNG (CMS login screen). |
| `og-image.png` | 1200x630 social-share card (Facebook, LinkedIn, WhatsApp, X). |
| `icon-192.png`, `icon-512.png` | Home-screen / PWA icons (see `/site.webmanifest`). |

Favicons live at `/favicon.ico` (16/32/48), `/assets/icons/favicon.svg` and `/apple-touch-icon.png` (180x180).
